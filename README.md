# Next.js Project: company_portfolio_2_next

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

### Commands

- **Development mode:** `npm run dev`
- **Build for production:** `npm run build`
- **Test built version:** `npm run start`
- **Run ESLint:** `npm run eslint`
- **Run ESLint fix:** `npm run eslint:fix`
- **Run Stylelint:** `npm run stylelint`
- **Run Stylelint fix:** `npm run stylelint:fix`

## Added Support Details

1. **ESLint**: Configured linting setup for JavaScript/TypeScript.
